# Grind

A fresh-start study planner. No chapters, completion history, or progress are seeded into the app.

## Reset model
- Legacy `grind1`, `grind2`, `grind3` local data is ignored and removed.
- Version 4 uses its own local storage namespace and a fresh device key.
- New users start with 0 chapters, 0 lectures, 0 DPPs, and 0 activity logs.
- Firebase sync remains available through the existing device-link flow.

## UI
The interface uses one consistent Inter/DM Mono type system, layered glass surfaces, blur, highlights, shadows, and depth-aware controls.
